# Hiệu ứng âm thanh (SFX)

Mặc định game tự tạo tiếng chém bằng WebAudio nên thư mục này có thể để trống.
Muốn dùng file riêng: thả file vào đây (ogg/mp3) rồi điền đường dẫn vào `files`
của tiếng tương ứng trong `js/data/sfx.js` (ví dụ `slash_hit`, `slash_crit`).
Chỉ dùng file bạn có quyền sử dụng.
